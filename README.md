# Optimath 📐

### Making Mathematics Visual.

**Optimath** is an educational initiative dedicated to making mathematics, statistics, machine learning, and engineering concepts easier to understand through mathematical animation.

This repository contains the **Python source code used to create the animations featured on the Optimath social media pages**. Using [Manim](https://www.manim.community/), complex equations, abstract mathematical ideas, and technical concepts are transformed into visual explanations.

The idea is simple: **make abstract concepts easier to see, explore, and understand.**

## 📚 Topics Covered

The animations explore a range of mathematical and technical subjects, including:

- **Mathematics & Numerical Methods** — Integration, numerical approximation, root-finding methods, and mathematical theorems.
- **Probability & Statistics** — Probability distributions and statistical concepts.
- **Machine Learning & AI** — Logistic regression, activation functions, and computational methods.
- **Civil & Structural Engineering** — Mathematical principles underlying engineering problems, including stress distribution in soils.
- **Earthquake Engineering** — Visualization of earthquake ground-motion records and related concepts.

The repository also includes introductory and experimental animation projects.

## 🎬 From Code to Animation

Every animation begins with mathematical ideas translated into Python code and brought to life using Manim.

This repository preserves the code behind these visualizations, offering a closer look at how mathematical animations are designed and developed.

Whether you're interested in mathematics, engineering, programming, or educational content creation, feel free to explore the projects.

## 🛠️ Technologies

- **Python** — For implementing mathematical logic and animation sequences.
- **Manim Community Edition** — For creating mathematical animations.
- **LaTeX** — For typesetting mathematical expressions.
